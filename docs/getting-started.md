# 开始使用

## Mac

公开版可用后，从本仓库的 **Releases** 打开 Mac 发布说明，按其中的系统与芯片要求下载 `.dmg`。打开磁盘映像，将「去多远」拖到「应用程序」，再从「应用程序」打开。

如果同时下载了 `.sha256.txt`，可在终端运行 `shasum -a 256 `，把 DMG 从 Finder 拖到命令末尾后按回车。将输出开头的 64 位十六进制字符与校验文件比对。遇到哈希不符或 macOS 无法验证开发者，请暂停安装并[反馈](../SUPPORT.md)。

## iPhone

收到开发者的 TestFlight 邀请后，用 iPhone 打开邀请，在 TestFlight 内安装。系统版本、测试范围和有效期以对应邀请和构建说明为准。GitHub Releases 不提供 iPhone 安装包。

## 算一趟

打开应用后先完成发行状态核验。核验不通过时，检查网络并重试；版本暂停时，查看发行公告。

1. 如果知道路程，选择「已知里程，直接计算」。如果要查看真实路线，连接地图后搜索或点选起点与目的地，并确认地点。
2. 填写百公里油耗和每升油价。地点路线可查看不同路线的距离、时间和费用。单程与往返按当前选项计算。
3. 查看账单。油费按总里程乘以百公里油耗、除以 100，再乘以每升油价；界面会把通行费单独显示。
4. 若当前版本支持，可将账单保存为图片或导出账单数据。分享前检查起终点和地址。

「按油费 / 时间探索」适合还没选好目的地的时候。先选择起点，再设定预算或时间；对想去的地点点选核算后，以该地点返回的具体路线报价为准。
