# 常见问题

**没连地图能算吗？**  
发行状态核验通过后，知道里程就可以直接算。地点搜索、地图、路线查询和按预算或时间探索需要网络及可用的高德地图连接。

**App 显示暂时无法确认版本怎么办？**  
先检查网络，再重试版本核验。首次启动、已缓存的核验结果过期或版本被暂停时，功能可能暂不可用。若提示版本暂停，请查看本仓库的发行公告。

**为什么去程和回程里程可能不同？**  
道路方向、路线策略和当次规划结果可能不同。使用地图时，往返结算以实际返回的去程和回程为准。手动输入请按界面里的单程／往返及里程提示填写。

**油费等于全部出行花费吗？**  
油费来自里程、油耗和单价。通行费独立显示，计划预算时还应考虑停车等其他开销。无法取得通行费数据时，不要当作免费。

**为什么探索范围和具体地点的结果可能不同？**  
探索区域是采样估算，未覆盖处可能尚未充分核验。点选具体地点后，App 会尝试查该地点的路线。计划出发时以具体核算和当时道路状况为准。

**GitHub 的 `Source code` ZIP 能用来安装吗？**  
那是 GitHub 自动打包的公开仓库内容，包含说明和发行资料。Mac 安装请下载发布页的 DMG；iPhone 安装请使用 TestFlight 邀请。

**遇到地图鉴权或定位错误怎么办？**  
先确认网络和当前地图连接。如果设备不允许定位，可改为搜索起点、在地图上选点，或直接输入已知里程。反馈时请勿附上地图 Key 或安全码。
