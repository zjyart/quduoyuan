# 隐私说明草案

本说明描述「去多远」当前功能基线的数据处理。正式发布的各平台版本将在核对其数据流后更新本说明。

| 数据 | 用途与处理方式 |
| --- | --- |
| 发行状态核验 | 应用启动或在前台使用时，会向发行状态服务请求当前平台、应用版本和构建号对应的可用状态。请求不包含已输入的行程、地址、定位或地图凭证。连接本身会传递 IP 等网络信息。应用会在设备上保存最近一次经过验证的响应。 |
| 车辆、油耗、油价和显示偏好 | 保存在应用的本机数据区，用于恢复设置。手动输入里程的油费在设备上计算，不需要发送该里程给高德。 |
| 收藏、最近地点与上一趟 | 本机保存已确认地点的信息与行程摘要，方便继续使用。重新搜索、逆查地址或算路时，相关地点信息会用来请求地图服务。 |
| 地点搜索、路线和地图 | 使用高德开放平台 JS API，按功能也可能调用高德 Web 服务。搜索词、搜索中心、地图范围、起终点坐标和路线策略等按请求需要发送给高德；网络请求也会向该服务暴露 IP 等连接信息。 |
| 当前位置 | 选择「当前位置」时会尝试获取位置，用于确认起点或搜索附近；定位及逆地理编码可能由高德参与。可以拒绝定位，改为搜索、点选或手动输入里程。 |
| 地图连接信息 | 如果版本提供自定义地图配置，选择记住连接时保存对应配置；修改连接时可能在会话中暂存。请勿分享或公开地图凭证。 |
| 导出与反馈 | 小票图片和账单数据由设备生成，可能包含地址、日期与费用。你选择保存或分享的去向决定谁能看到它。提交 GitHub Issue 或 TestFlight 反馈时，相关平台按各自政策处理你提供的信息。 |

可以在系统设置中管理位置权限。地图服务由高德提供，相关处理与用户权利见[高德地图开放平台隐私权政策](https://developer.amap.com/pages/privacy/)。关于位置或个人数据的咨询，请通过[私下反馈方式](../SECURITY.md)联系。
